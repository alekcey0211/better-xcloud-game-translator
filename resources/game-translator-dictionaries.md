# Русификатор вместо онлайн-перевода

## Включение на Quest

1. Полностью перезапустите Better xCloud с ранее установленным загрузчиком GitHub Pages.
2. В настройках Better xCloud откройте **Game Translator (English → Russian)**.
3. Включите **Enable Game Translator**.
4. Выберите **Translation provider → Game dictionary only (no fallback)**.
5. В **Game dictionary / Русификатор** выберите **The Blood of Dawnwalker — clarkkent (RU)**.
6. В игре включите английские субтитры. При запуске трансляции дождитесь уведомления «Русификатор готов».

Сохранённый ранее MyMemory не переключается автоматически: выберите новый провайдер вручную.
API-ключ, прокси, локальный сервер и перенос файлов на Quest не нужны.

Стартовые настройки: OCR region **Bottom 35%**, Subtitle scan interval **333 ms**,
Text stabilization **250 ms**, Minimum translation display time **5 s**,
Show recognized English text **Off**. Это отправная точка, не гарантия идеального OCR.

## Поведение

- Загружается один статический JSON со словарём выбранной игры (~3,5 МБ для Dawnwalker).
- После загрузки поиск выполняется локально; английские реплики никуда не отправляются.
- Совпадение показывает готовый русский текст. Неизвестная или неоднозначная реплика сразу скрывает перевод, включая предыдущий и английский текст.
- Если субтитры просто исчезли, последний успешный перевод остаётся на время чтения из настроек.
- Ошибка загрузки не включает другой провайдер. Диагностика загрузки — отдельное уведомление, не субтитр «Translation unavailable».
- MyMemory, Chrome Translator и DeepL сохранены как отдельные явно выбираемые режимы. В режиме словаря они не вызываются.
- В памяти словарь переиспользуется; версионированный URL также позволяет браузеру использовать HTTP-кеш. Постоянная офлайн-доступность после перезапуска не гарантируется.
- OCR-модель загружается отдельно, как раньше. Русификатор не убирает задержку распознавания изображения.

## Данные и ограничения

Исходник предоставлен пользователем: `The_Blood_of_Dawnwalker_RUS_by_clarkkent_v1`.
В его README указана версия **1.0.7**. Автор перевода — [clarkkent](https://boosty.to/clarkkent).
Перевод является сторонним материалом и не перелицензируется под MIT вместе с кодом Better xCloud.

Использован только `Dialogues_All/en/Dialogues_All.locres`: 43 694 записи.
После удаления дубликатов, 426 неоднозначных хешей и строк без русского текста:
35 692 хеша и 34 881 уникальная русская строка. Интерфейс, шрифты, видео,
исполняемые файлы и исходный PAK в репозиторий не включены.

В исходнике нет английских строк: есть их Unreal CRC32 и русский текст.
Поиск рассчитывает CRC32 английской реплики, проверяет варианты без имени говорящего,
с нормализованными пробелами/кавычками, исправлением отдельного `|` → `I`
и восстановленной отсутствующей конечной пунктуацией. Если варианты дают разные
переводы, результат не показывается. Регистр и слова не заменяются произвольно.

По одним CRC32 невозможно построить полноценный нечёткий поиск по похожим фразам.
Для него нужен английский текст из соответствующей версии игры. Также остаётся
теоретическая возможность невыявленных коллизий CRC32. Уже выявленные неоднозначные
хеши исключены. Контекстные варианты перевода с одной английской фразой пропускаются,
поскольку OCR не содержит внутреннего ID диалога.

## Воспроизводимая подготовка

Из корня репозитория:

```bash
python3 scripts/prepare-game-dictionary.py /path/to/Dawnwalker-Windows_RU_P.pak .github/pages/dictionaries
npm run test:game-translator
npm run test:game-translator:video
bun tests/game-translator-service.test.ts
```

Конвертер поддерживает конкретный формат: незашифрованный PAK v3 и locres v3.
Проверяет SHA1 индекса и выбранного файла, границы таблиц и индексы строк.
Ничего из архива не запускает и не извлекает по архивным путям.
Имя JSON содержит начало SHA256 его содержимого; полный SHA256 исходного PAK
сохранён в метаданных. Повторная обработка того же PAK даёт идентичный JSON.

После обновления пакета обновите ссылку в `src/modules/game-translator/dictionary-catalog.ts`,
ожидания тестов и пересоберите userscript. Workflow `deploy-pages.yml` копирует
словарь вместе со сборкой на GitHub Pages. JSON не включён в userscript, поэтому
другие провайдеры его не загружают.

## Проверки

Видеорегрессия использует семь подготовленных кадров пользовательской записи:
шесть реплик должны дать точный русский перевод из пакета после настоящего OCR;
кадр без субтитров должен остаться пустым. Это не проверка всех диалогов игры
и не запуск на физическом Quest.

### Браузерная проверка загрузчика

Node-моки не проверяют требование браузерного `fetch` к контексту вызова.
Для проверки настоящего `window.fetch`, загрузки опубликованного словаря и
пустого результата для неизвестной фразы:

```bash
mkdir -p .cache/dictionary-browser-check
bun build tests/browser/dictionary-loading.ts --outfile .cache/dictionary-browser-check/check.js --target browser
cp tests/browser/dictionary-loading.html .cache/dictionary-browser-check/index.html
python3 -m http.server 8766 --bind 127.0.0.1 --directory .cache/dictionary-browser-check
```

Откройте `http://127.0.0.1:8766` в браузере и дождитесь **PASS**.
Тест использует настоящий провайдер и передаёт ему небиндированный `window.fetch`,
как основной userscript. Он не вызывает онлайн-переводчики.
